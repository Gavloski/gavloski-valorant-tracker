# Gavloski Valorant Tracker

Painel pessoal e responsivo para acompanhar as partidas competitivas de **Gavloski#Белла**.

## Recursos

- Rank e RR atual
- K/D, ACS, headshot e win rate recentes
- Histórico das últimas partidas competitivas
- Recomendação automática de foco
- Publicação automática no GitHub Pages

Os dados são consultados no navegador por meio da API pública HenrikDev. Nenhuma senha da Riot é usada ou armazenada.

## Publicação

Em **Settings → Pages**, selecione **GitHub Actions** como fonte. O workflow publicará o site automaticamente.

> Projeto pessoal, sem afiliação com Riot Games ou Tracker Network.
